# Instrument images

SVG layers from [flight-indicators-js](https://www.npmjs.com/package/flight-indicators-js) 1.0.5
(MIT, © 2021 Teocci, see `LICENSE`), vendored so the cockpit can draw them into one canvas.
Only change: the remote Google Fonts `@import` lines were removed (an SVG drawn as an image can't load them).
