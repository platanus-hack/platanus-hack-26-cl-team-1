## Done
- Box: container, root, Ubuntu 24.04, RTX 5090 32 GB, driver 580 (CUDA 13.0), `nvcc` 12.9, 61 GB RAM, no
  systemd, no rsync or curl.
- vLLM 0.34 in `~/sup/venvs/vllm`. Two fixes were needed:
  - **uv-managed Python:** the system Python lacks `Python.h`, so Triton failed at startup.
  - **`VLLM_USE_DEEP_GEMM=0`:** DeepGEMM SM120 kernels need CUDA ≥ 13, and the box's `nvcc` is 12.9.
- `gpu/setup-5090.sh`, `gpu/vllm-5090.sh`, `gpu/up-5090.sh` (one command from a laptop: setup, start,
  `ssh -L 8001`), and a README section with the results.
- Bench, 4 public photos × 3 (p50 / p95):
  - 8B FP8: 437 / 512 ms on hand hygiene, 395 / 932 ms on the robot task.
  - 2B BF16: 266 / 319 ms and 491 / 559 ms.
  - The 8B answers `null` on every off-task photo.
- End to end over `/ws/session` with real JPEGs: observations ~480 ms, one every ~1.5 s. `wet` advanced
  with "Bien. Ahora aplica jabón…". A lathered frame read as `rub_palms` was flagged `out_of_order`.
